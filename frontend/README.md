# Frontend ИЖС платформы

Vue 3 + TypeScript, Element Plus, Tailwind CSS 4, Pinia, Vue Router 5, Socket.IO, Vite 8. Node.js 22.12+.

## Команды

```sh
npm ci
npm run dev        # http://localhost:5173, прокси /api, /uploads и /socket.io на http://localhost:4000
npm run lint
npm test           # модульные тесты Vitest
npm run build      # проверка типов и production-сборка в dist/
```

Адрес API для dev-прокси меняется переменной `VITE_DEV_API`. В production SPA и API работают на одном домене за Caddy (`/api`, `/uploads`, `/socket.io`), `VITE_API_URL` по умолчанию `/api`.

## Структура

- `api/` — HTTP-клиент (токен доступа только в памяти, CSRF для cookie-запросов, один общий refresh на параллельные `401`, русские сообщения об ошибках), типы ответов и функции всех эндпоинтов.
- `realtime/` — одно соединение Socket.IO. Подписки на комнаты повторяются после каждого переподключения; после отключения сервером клиент обновляет сессию и подключается снова.
- `stores/` — сессия, уведомления, тема.
- `router/` — маршруты, доступ по ролям, мета-теги. Адреса прежнего интерфейса сохранены.
- `layouts/` — публичная часть, страницы входа, кабинет с меню по роли.
- `features/` — экраны по разделам: витрина, вход и регистрация, восстановление пароля, каталог и карточка объекта, заявки, чаты, мероприятия, новости, тарифы, уведомления, профиль, администрирование, правовые документы.
- `components/` — общие элементы: статусы, пустые и ошибочные состояния, скелетоны, виджет поддержки, cookie-баннер.

## Дизайн-система

- Один акцентный цвет: кобальт из логотипа (`#1a56a6` в светлой теме, `#6ea3e6` в тёмной), холодные нейтральные тона. Зелёный, янтарный и красный используются только для статусов.
- Шрифты Onest (с кириллицей) и JetBrains Mono для номеров, оба подключены локально через Fontsource.
- Радиусы: элементы управления 10px, поверхности 14px, теги статусов полностью скруглены.
- Светлая и тёмная тема: по умолчанию как в системе, переключатель в шапке, выбор хранится в `localStorage`.
- Иконки Tabler с единой толщиной линии.
- Токены описаны CSS-переменными в `styles/main.css` и переопределяют переменные Element Plus. CSS Element Plus лежит в каскадном слое между сбросом Tailwind и утилитами, поэтому утилиты могут дополнять компоненты.
- Анимации короткие и отключаются при `prefers-reduced-motion`.

## Карта и адреса

Карта объекта и выбор точки в форме работают на [MapLibre GL](https://maplibre.org) с векторными тайлами [OpenFreeMap](https://openfreemap.org): бесплатно, без ключа и без ограничений числа показов. Подпись источников обязательна и выводится MapLibre. Компонент `components/map/PropertyMap.vue` загружается только на страницах объекта; воркер MapLibre подключён явно через `?worker&url`, иначе после сборки он не находится. Подсказки адресов приходят от backend (DaData), браузер к DaData не обращается.

## Совместимость

Ключи `localStorage` прежнего интерфейса сохранены: согласие на cookie (`cookie_consent`) и гостевая сессия поддержки (`chat_guest_session`). Тексты правовых документов перенесены из прежнего интерфейса без изменений. В редакции от 03.10.2026 политика конфиденциальности дополнена сведениями о картографическом сервисе OpenFreeMap (разделы 6 и 7) и сервисе подсказок адресов DaData (раздел 6), версия документов в согласиях при регистрации (`LEGAL_DOC_VERSION`) обновлена до `2026-10-03`.
